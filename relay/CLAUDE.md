# Katana Duel — правила для Claude

Некоммерческая браузерная игра: дуэли 1 на 1 онлайн в духе Sekiro. Живая версия: https://onevs1.onrender.com/ (Render, ветка main).
Этот репозиторий = папка `relay/` из локального проекта (Electron-версия с `server/`, `dist/`, `tools/` живёт только локально и сюда не попадает).

## Правила работы с репо
- Коммитим только содержимое этого репо (= relay/). Файлы локального проекта вне relay/ сюда не добавлять.
- Только `git add <конкретный путь>`, никогда `git add .` / `-A`. Перед каждым коммитом — `git status`.
- Перед работой — `git pull`. Работаем в ветках, вливаем через Pull Request (main = живая игра). Пуш прямо в main — только по явной просьбе.
- Сырые Mixamo FBX не коммитить (они в .gitignore) — только итоговый GLB (`app/assets/kd_mixamo.glb`) и код.
- Экономим токены: grep по именам, точечные правки; файлы целиком не читать и не переписывать (строки очень длинные). Числа (тайминги, силы, окна) — в константы вверху файлов или в MOVES.
- После каждой фичи — проверка против AI и онлайн, краткий отчёт: что изменено, какие файлы.
- Сообщения коммитов — коротко, по-русски или по-английски, по делу.

## Запуск
`npm install && npm start` → http://localhost:3000 (server.js раздаёт app/ и Socket.IO-комнаты по коду).

## Карта проекта
- `server.js` — Express + Socket.IO: раздача app/, комнаты по 4-буквенному коду (2 места, для 2 на 2 — 4; старт по `tmstart` хоста, сообщения `tm` с номером отправителя), `/sfx-list`, `/health`.
- `app/index.html`, `app/style.css` — меню, HUD, экраны (importmap на /vendor/three).
- `app/js/main.js` — игровой цикл, ввод, режимы (Gauntlet, Duel vs AI, Training, Online), HUD, `showResult` (эффекты исходов), загрузка клипов, отладочные `window.__dbg/__step/__inp`.
- `app/js/fighter.js` — боец: состояния, `resolveStrike`, движение/прыжок/уворот, слои анимации (full-body + низ/верх), процедурные кости, IK, крепление меча, `prepareClips`.
- `app/js/moves.js` — данные приёмов `MOVES` (атаки) и `REACT` (реакции): segs = куски клипов с игровыми длительностями, hit/cancel/lunge/track/dmg/post, цепочки `next` (ЛКМ) и `nextHeavy` (E).
- `app/js/ai.js` — AI противника (уровни, парирования, выбор атак).
- `app/js/camera.js` — камера из-за правого плеча, лок-он.
- `app/js/post.js` — пост-обработка (Bloom, Bokeh, Output, шейдер Grade).
- `app/js/arena.js` — дуэльные арены (додзё и др.), регистрация open-world миров.
- `app/js/world.js` — кит открытых карт: рельеф, коллайдеры, линия видимости, поверхности, разрушаемые пропсы, погода.
- `app/js/maps.js` — открытые карты Hunt/Survival из фиксированного сида, пресеты времени суток. Survival (`SV_MAPS`): Dojo Court, Cave Grottos, Trade Post, Bamboo Crossing, Sunken Ruins, Castle Courtyard, Ruined Fortress; старые ключи sv_temple/sv_village/sv_glade открывают их замены.
- `app/js/vista.js` — окружение за краем открытых карт (все локации: 7 арен Survival, Shadow Hunt, дуэльные snow, sakura (только далёкие снежные горы и момидзи), bamboo; Night Dojo не трогаем): ближний план — рельеф, вырастающий из земли карты (те же цвета и текстура), настоящие деревья foliage.js, валуны по склону, руины стен, водопад, продолжение реки/берега; средний — хребты, обрывы, долины с туманом, ~2200 низкополигональных деревьев (инстансинг по секторам), храмы/пагоды/замки/деревни/тории (одним мешем), тропы; дальний — три освещённых хребта со снежными шапками и облака (один InstancedMesh). Дымка с потолком (`hazed`: силуэты не растворяются в плоскую стену), горизонт неба = цвет тумана (`fc/fk` в gradSky). Стороны карты по компасу (N = −Z) в `AROUND` (maps.js) / `duelVista` (arena.js): mountain, cliff, forest, hills, valley, lake. Ничего не коллайдит (всё за границей), тени не отбрасывает; low-качество — без ближних деревьев и облаков. Камера far = 900, небо `SKY_R` = 780. Тест-хук `globalThis.KD_NO_VISTA`.
- `app/js/svprops.js` — пропсы арен Survival: галереи, макивара, заборы, Дзидзо, свечи, лавки, тележки, колодец, лодки, пирс, сушилки сетей, скалы (`crag`/`cliff`), каменные арки, брод из камней, гирлянды фонарей, знамёна, жаровни, полированный пол (`FLOOR`: мягкий блик без зеркала).
- `app/js/fx.js` — частицы, искры, следы клинка, вспышки.
- `app/js/audio.js` — звук: банк `assets/sfx` (`play(cat)`: дубли без повтора, разброс питча/громкости, лимит голосов, «глушение» звона стали новой сталью; серия парирований чуть повышает тон), синтез — запасной вариант; `setSpace` — своя реверберация по локации; `amb` — фон локации из `assets/amb` + дождь по погоде + редкие детали; ducking музыки на сильных ударах; выход: лимитер без авто-подъёма + мягкий клиппер; `music` — саундтрек локаций: тема по карте (`themeFor`), состояния off/explore/tension/combat/boss; при бое сначала вступают барабаны, затем на сильную долю — доп. слой, при выходе — в обратном порядке. Спокойные темы локаций играют в меню и в Shadow Hunt; во всех боях (дуэли, Gauntlet, онлайн, 2 на 2, Survival, дуэль Hunt в 12:30) — `battle`: случайная из 4 песен Егора на матч (не одна и та же подряд), интро песни на поклоне (если поклон дольше — луп последних 8 долей), `drop()` на ближайшую половину такта — с места дропа песни, драка — бесшовный луп до конца матча; раунды музыку не перезапускают; карта на это время молчит (`music.hold`). Дуэли ведёт `music()` в main.js по фазам, режимы — сами.
- `app/js/net.js` — обёртка Socket.IO-клиента.
- `app/js/gear.js` — экипировка: катана, ножны, одежда, броня, верлет-ткань; скины и клинки Armory.
- `app/js/binds.js` — перебинд клавиш (localStorage).
- `app/js/i18n.js` — строки EN/RU/UK.
- `app/js/stealth.js` — обнаружение (зрение/слух) для Samurai Hunt.
- `app/js/modes/hunt.js` — режим Shadow Hunt: часы ночь→12:30 (`DAY` в maps.js: свет, туман, дымка), танто в охоте, кусты и туман для скрытности, бросок камня, в 12:30 — дуэль на площади катанами.
- `app/js/modes/survival.js` — кооп/соло волны врагов. Ум ботов (`SKILL`) зависит только от волны, не от типа/скина: основная масса — слабые…средние (диапазон `base`), 1–2 «вожака» на ступень выше (средние → сильные к 9-й волне); тип задаёт только стиль (роль, дистанция, подвижность) и слабости (`styleK`). Мини-боссы (5, 8) и босс 10-й волны бьют фиксированным паттерном (`pattern`: одни и те же комбо по кругу, после каждого — окно `gap`, где босс отходит и почти не защищается; каждая фаза добавляет новое). Дробный уровень ИИ (0..2) смешивает профили в ai.js.
- `app/js/modes/team.js` — режим 2 на 2: 4 места (команда = место % 2), пустые места — боты хоста; сообщения `tm` (st/strike/out/ph), раунды до 2 побед.
- `app/js/modes/svabil.js` — умения боссов Survival: зажигательная бомба мини-боссов (огонь 3×3 м, горение, один таймер урона на игрока), крюк с цепью финального босса (парирование при контакте, притягивание без авто-удара), призыв асигару; константы `ABIL`.
- `app/js/modes/svitems.js` — фляги лечения и сюрикен Survival.
- `app/js/modes/huntitems.js` — брошенный камень Shadow Hunt (дуга, шум в точке падения).
- `app/js/achievements.js` — 48 достижений (`ACH`: id, кандзи, стат, цель, монеты, кристаллы), прогресс в `REC.ach`, события `ach.add/max` из режимов; награда платится один раз (`REC.ach.paid`).
- Валюты: монеты `REC.coins` и кристаллы `REC.gems` (`addGems` в main.js): 1–2 за победу в бою, 40/60 за Выживание (обычная/сложная, `SV_GEMS`), награды достижений. Цены в `WEAPONS`/`OUTFITS`: `price` (монеты) и/или `gems`; только `gems` = только за кристаллы; `unlock: 'survival'` (Oni's Bane) не продаётся.
- `app/js/armory.js` — 3D-зал Арсенала: подиумы, карусель, мечи горизонтально, вращение мышью и в простое (`ARM`); рендерится вместо игры, пока открыт экран.
- `app/assets/ui/pv_*.jpg` — превью режимов на экране Play (кадры из игры).
- `app/js/foliage.js` — процедурные деревья, бамбук, трава; ветер в шейдере; леса по ячейкам 48 м; качество через `setFoliageQuality`. Виды (`TREE_KINDS`): японские сосны `matsu` (облачная стрижка) и `bonsai` (низкая, кривая), `keyaki` (высокий дзельква), `kusu` (камфорный, широкий зонт), `tsubaki` (низкая камелия), `sakura`, клёны `momiji`/`momijiLow`/`momijiTall`, `bare`, ели `pine`/`snowpine`; форма кроны `form` (pad/vase/spread/round) и изгиб ствола `bend`.
- **Правило деревьев (Егор):** ель — только на зимних картах, а на зимних картах — только заснеженные ели (никаких зелёных, красных, сухих); на остальных — японские сосны/бонсай, бамбук, японские лиственные; сакура — только где на карте уже есть розовое; момидзи — только на Momiji Field. Виды растут рощами (не вперемешку), формы разные.
- `app/js/arch.js` — архитектура: тории, каменные фонари, черепичные крыши, решётки, стены исигаки, арочные мосты, камни с мхом, «грязь» у основания.
- `app/js/tune.js` — панель настройки (F9): MOVES и группы констант из `fighter.js` (`TUNE`) и `camera.js` (`CAM`), сохранение в localStorage, выгрузка JSON.
- `app/assets/music/{itsutsu,toukou,toukou2,eikou}_{intro,fight}.ogg` — боевые песни Егора (五つの動機 136 BPM, 刀光の隙間 133, 刀光の隙間 2 141, 栄光の決闘 141): интро = начало песни до дропа, драка = от дропа до точки петли (конец сведён кроссфейдом в такт перед дропом); стерео 32 кГц Vorbis, драка −18.4 LUFS как темы локаций (интро с тем же усилением), EQ: срез ниже 30 Гц и провал 2.6–5 кГц под звуки клинков. Подготовка — локально `tools/fightmusic.py` (таблица `SONGS`: темп, фаза доли, такты интро/дропа/петли).
- `app/assets/music/<тема>_{base,perc,layer}.ogg` — 5 оригинальных тем (momiji, dojo, bamboo, winter, town), ~2:20 бесшовные петли, 3 стема одинаковой длины (спокойный фон / барабаны боя / доп. слой боя); генератор — локально `tools/musicgen.py` (numpy+scipy+ffmpeg, всё синтезом, без сэмплов).
- `app/assets/sfx/<категория>_<nn>.ogg` — 177 звуков / 58 категорий, все созданы с нуля в `tools/sfxgen.py` (локально): 48 кГц моно, одна цепочка мастеринга, иерархия громкости (макс. моментальная LUFS) с запасом 6 дБ; `app/assets/amb/*.ogg` — бесшовные стерео-фоны локаций (momiji, dojo, bamboo, winter, town, rain). Референсы только анализировались, в игру не попадают.
- `app/assets/bg/*.svg` — фоны горизонта (горы, снежные горы, ночные горы, бамбук, лес сакуры): тайлящиеся полосы на цилиндрах вокруг карты, `BACKDROPS` в arena.js; генератор — локально `tools/bggen.py`.
- `app/assets/kd_ual1.glb`, `kd_ual2.glb` — модель + клипы Quaternius UAL (CC0); `kd_mixamo.glb` — Mixamo-клипы `MX_*`, перенесённые на этот скелет (только анимация).

## Онлайн
Ranked: сервер держит очередь (`queue`/`unqueue`), сводит ближайших по рейтингу (окно растёт с ожиданием) в комнату 1 на 1 с `meta.r`; рейтинг Elo хранится у каждого в `REC.rating` (`RANK` в main.js).
Главное меню: фоном идёт показательный бой двух ботов (`DEMO` в main.js, камера `demo` в camera.js), ничего не засчитывается.
Каждый клиент симулирует своего бойца и шлёт `state`. Атакующий сам детектит попадание клинком → шлёт `strike` → защитник решает исход у себя в `resolveStrike` → шлёт `outcome` → атакующий применяет `applyOutcome`. Также `round`, `rematch`, `start`, `peerleft`.

## Анимации
- Клипы: UAL (CC0) + Mixamo. Ассеты Sekiro не используем (только как референс ритма).
- Mixamo → игра: локально `tools/retarget.html` (запуск `node tools/retarget.cjs` при работающем `node dev.js`), исходники `mixamo/*.fbx` — только локально. Горизонтальное смещение корня убирается, его заменяет `lunge` в MOVES; таблица смещений — `tools/kd_mixamo.meta.json`.

## План работ
1. Подготовка: CLAUDE.md, атаки в данных, ползунки таймингов в игре (lil-gui).
2. Анимации: Mixamo-клипы (сделано: лёгкая серия, тяжёлая серия E×3, прыжковая атака, смерть, спринт); докачать block, hit reaction, dodge, roll, kick, jump, uppercut; IK левой руки на рукоять.
3. Найденные баги: голова крутится поверх анимации; «поклоны» от процедурного наклона спины; прыжок «на месте»; пересветы (особенно снег).
4. Боевой набор v4 (упрощённый, сделано): игроку — только ЛКМ×3 (slash1-3) и E×3 (heavy-heavy3) на цепочках UAL Sword_Light/Heavy_A-B-C (связки без разрыва: cancel = начало _Rec), удар об землю только в верхней точке прыжка (plunge), уворот+ЛКМ = stepCut, уворот+E = dashCut, блок двумя руками. Уникальные атаки остаются только у AI (dash, thrust, kick, uppercut, sweep, crush, grab, heavyB/C, leap, boss1-3).
   Ноги: `footLock` в fighter.js прибивает опорную стопу (FOOT в TUNE), lunge не катит тело по полу; `glide: true` в MOVES — исключение для рывков, где lunge идёт строго во время шага.
5. Импакт: вес оружия, сэмплы звука, кровь, реакции.
6. Добивания данными (клипы/позы атакующего и жертвы, камера, события), редактор поз.
7. Стиль Valheim (опционально), тяжёлое оружие/враги, сеть.
